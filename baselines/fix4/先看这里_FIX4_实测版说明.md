# 小车循迹 FIX4：实测编码器、漏弯和弯道稳定修复版

基于之前的 FIX3 工程修改，结合你新发的三个视频，以及左右轮 10 圈计数、30%/40% PWM 测速。原接线、按键、电机和编码器方向保持原工程设置。编码器仍使用原下降沿条件解码，测得的计数直接用于本版。

## 下载及操作

直接烧录 `Objects/linefollow_calibrated_fix4.hex`，或打开 `tracking_square_continuous.uvprojx`，使用 Keil ARM Compiler 5 编译。

上电准备状态显示 **`FIX4 K1:TRACK`**，确认刷入本次循迹版。将中间探头放在黑线处，按 **KEY1** 开始循迹，再按停车；KEY0、KEY2 也停车。

**KEY5 仍是固定 30% PWM 人工直行检查，会忽略黑线。试跑循迹使用 KEY1。** 编码器测量版的 KEY2 清零、KEY5 40% 功能不适用于本循迹版。

## 实测值已代入

| 参数 | 左轮 | 右轮 |
| --- | ---: | ---: |
| 前进 10 圈，第一次 | 2516 | 2656 |
| 前进 10 圈，第二次 | 2504 | 2651 |
| 每圈计数，取两次平均 | **251.0** | **265.35** |
| 30% PWM 的 PPS | 2011 | 2244 |
| 30% PWM 换算 RPM | 480.72 | 507.41 |
| 40% PWM 的 PPS | 2866 | 3130 |
| 40% PWM 换算 RPM | 685.10 | 707.74 |

每圈计数 = 两次 10 圈计数之和 ÷ 20；RPM = PPS × 60 ÷ 每圈计数。你给出的计数按正向读数处理，方向配置沿用测量程序。

轮胎外径 **44 mm**、轮距 **133 mm**、探头前置距离 **175 mm**，继续使用你确认的尺寸。原始数据和换算值见 `实测参数记录.json`。

旧工程填 1000，会把真实速度和距离算成实际的约 1/4。左右实际计数又不同，误差倍率也不同。轮轴推进按错误距离判断时会走得过长，转角判断也会偏晚。本版速度、每轮距离及转角均分别使用 251.0 / 265.35。

## 针对视频问题的修改

1. **转弯推进使用实测距离。** 强横带离开后，根据 175 mm 前置距离、横带宽度和已走距离推进轮轴；到位后才低速旋转。修正原 1000 带来的长距离直行。
2. **减少角点漏判。** 横带候选容许中间漏读一两帧，仍要求两帧宽线确认；孤立的一帧不能触发长推进。角点中间短暂出现四五路黑线，也不会立即被学成“普通线宽”。
3. **旁侧有线及时跟随。** 保留中线旁唯一单侧黑区的确认和转向记忆；短暂全白共同缩放左右轮速，保留弯道差速。
4. **普通弧弯连续纠偏。** 中间探头跳变采用小死区、位置滤波及轮速变化限制。有线持续贴最外侧 600 ms 且无改善时，内轮停、外轮有限向前对线；不再短暂停车后反复反向扫描。确认中心线后直接柔和接回循迹。
5. **降低电机冲击。** 原 40%/120 ms 起步助推改为 18% 起步；仍无正向计数才在最后一帧升至 22%，总助推最多 40 ms。检测到运动即可取消。循迹闭环 PWM 上限为 30%。
6. **出弯保留负载补偿。** 速度环在有效运动、未明显超速时保存有上限的负载补偿，转弯阶段切换后继续使用；阶段误差、微分和轮速命令仍重置，手动停车全部清空。避免落地负载补偿每次出弯都从零开始。
7. **匹配真实速度与计数分辨率。** 两轮前馈分别按 30%/40% 空转数据给初值，减小旧速度 PI 增益，超速时撤去驱动并卸积分。20 ms 单计数约 12 RPM，控制和循迹显示使用适度滤波。

三个新视频分别是 `41cc…`（约 23.1 秒）、`56e3…`（约 15.6 秒）、`61e0…`（约 3.6 秒）。第一段可见弧弯中的多次停顿和大幅回摆；第二段包含直角转弯和直线摆动；短片可见探头经过角点后仍向前。短片无法读清屏幕，也不能仅凭车头位置区分当时正在推进轮轴还是没有识别角点，因此本版同时修正距离换算和角点断帧识别。时间轴截图见 `本次视频截图/`。

## 屏幕与试跑

| 显示 | 含义 |
| --- | --- |
| RUN | 连续循迹 |
| WIDE:WAIT EXIT | 已见强横带，等待离开 |
| AXLE ADVANCE | 按实测计数推进轮轴到角点 |
| TURN LEFT / TURN RIGHT | 低速直角找线 |
| EDGE CRAWL | 侧边持续有线，有限向前对线 |
| SEARCH LIMITED | 全白后有限搜索 |
| LINE REACQUIRED | 直角找线后的短暂稳定阶段 |
| ENC CHECK! STOP | 被命令运动的轮子长时间无计数或反馈反向 |
| LOST! K1:RETRY | 推进或有限找线未完成，已停车 |

第三行 L/R 为 RPM；循迹时显示速度环滤波值，人工直行检查显示当前采样值。IR 仍显示八路黑线检测，第四行在循迹时显示左右 PWM。

巡航目标 **60 真实 RPM**，44 mm 轮约 **138 mm/s**；直角推进 50 RPM、旋转 42 RPM。这里的数值已经改用实测计数，不能直接和旧屏幕显示的 RPM 比较。

先在原场地按 KEY1 低速试跑，观察完整直角和连续弧弯。若仍晚转，区分屏幕一直 `RUN`，还是已经 `AXLE ADVANCE`：前者关注黑线检测/校准，后者关注距离和车轮打滑。所有参数集中在 `hardware/CarConfig.h`；试跑前先使用本版默认值。

## 验证范围

本次最终源码已由 ARMCC 5.06 编译、链接并生成 HEX，无编译错误或警告。**53 项控制/校准回归、34 项必需几何场景通过**，HEX 校验和、Flash 地址和启动向量通过。源码/固件摘要及完整输出见 `tests/verification.txt` 和 `SHA256.json`。

回归测试执行实际 C 源码编译出的 Cortex-M3 指令，GPIO、编码器和 OLED 用测试替身。独立几何模型包括双向直角矩形、偏移/角度/线宽/前置距变化、200～600 mm 半径弯道，以及额外的负载假设场景。模型要求完成一圈多、直角矩形通过四角；普通弯道全程探头中心偏差小于 25 mm，矩形 RUN 偏差小于 35 mm。持续最外 1/2 路的接管判据采用 600 ms 检测加 400 ms 柔和恢复上限；三路边线允许持续过弯，并完整记录其时长。

34 个必需场景中，RUN 最大前探头误差 28.66 mm，持续最外 1/2 路的 RUN 最长 580 ms，累计搜索最长 0.76 秒。直角推进/旋转时探头允许暂时离线，全程误差可到 191.63 mm，不能把它称作全程贴线误差。

**空转两点无法确定低速起转门槛和落地负载。** 前馈低速值是初始外推，模型的摩擦、响应时间、12 mm 探头间距和线宽仍包含假设；本版未在你的车上烧录试跑。

额外更高摩擦的 10 项压力场景有 **6 项通过、4 项未通过**：三个圆弯超过 25 mm 边界，分别最大 30.01、25.62、27.92 mm；一个右转矩形有限找线后停车。它们不是实车测量，不计入必需场景的通过结论，保留于 `tests/pressure_results.json`。实际地面负载较大时仍可能需要进一步调低速起转与速度环参数。

重编译可执行 PowerShell `./build.ps1`；重跑验证可执行 `python tests/run_verification.py`（需要 ARMCC 5、Python 和 Unicorn）。测试目录不加入 Keil 固件编译。
