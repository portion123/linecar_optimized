## 每个运动状态的退出路径

| 状态 | 正常出口 | 未恢复时的有限出口 |
|---|---|---|
| TRACK | 角点候选→CONFIRM；失线→SEARCH；持续贴边→受控 pivot | 含糊分离黑区 240 ms 停；首次白线建立会话；反复短白线 2 s 后升级搜索 |
| CORNER_CONFIRM | 置信度≥4且宽线后白线≥40 ms→APPROACH；稳定原线撤销候选→TRACK | 1800 ms 或候选期间 100 mm 停 |
| CORNER_APPROACH | 距离达到目标且≥130 mm→TURN_FAST，弱/无方向进入有限 SEARCH | 超过 200 mm、偏航>15°、6000 ms、编码器故障或会话预算→停 |
| TURN_FAST / TURN_SLOW | 50°后慢转；70°后18 RPM；六帧可靠新线→ALIGN | 105°后仅局部反向15°；12000 ms、反向净转动10°或会话预算→停 |
| ALIGN | 连续中心160 ms→EXIT | 白线120 ms→局部 SEARCH；1800 ms、65 mm、附加20°或会话预算→停 |
| EXIT | 至少700 ms、合格线连续400 ms、前进25 mm→TRACK | 白线120 ms→预计方向附近 SEARCH；3000 ms或会话预算→停 |
| SEARCH | 六帧合格线→ALIGN | 普通最多两侧±60°，贴边35°/2500 ms，出弯附近15°，弱线索两侧12°，无方向300 ms；总体10000 ms或会话预算→停 |
| FORWARD | 按键→停止 | 原700 ms无脉冲/方向异常保护现也适用，另加15000 ms有限台架时间 |
| SPEED_TEST | 按键→停止 | 限速60 RPM、3000 ms及编码器故障保护 |
| READY / NO_LINE / STOP / ENCODER_FAULT / CONTROL_FAULT | 人工启动才恢复 | 每周期保持 PWM=0，不自动重试 |

所有运动状态还有共同的按键停止、编码器检测、调度间隔>40 ms停车保护。会话上限为12 s、4次尝试、累计绝对角度300°、两轮绝对路程平均700 mm，先触发的保护生效；局部状态的最大时间不是额外赠送的预算。

## 状态竞争、时间与数值

- **同一周期只由主循环改状态。** TIM3 不改状态；编码器中断只计数。按键在 Track_Task 前处理，停止后的任务入口以及 SetTargets/DriveTargets 都检查运行状态，防止“预算拒绝了 BeginScan，调用者继续驱动”的竞争。对应新增测试 `test_13_attempt_exhaustion_cannot_reapply_pwm`。
- **会话起点只有三个合法写入位置。** 首次 `RecoveryBegin`（Track.c:614），人工 Stop/Start 清空（:230），满足稳定 TRACK 时间和正向距离后清空（:632）。BeginScan 不改会话起点，只改局部 phase_started/turn_angle；在尝试上限检查后才增加尝试次数（:655）。
- **时间用 uint32 差值。** 全部超时采用 `now-start`，测试跨毫秒回绕；控制周期至少20 ms才计算 RPM/窗口，因此分母不为零。调度间隔异常先停车，不用大 dt 放大目标斜率（:952）。
- **计数提升到 int32 后才取符号。** 避免原 int16 的 -32768 经方向反转溢出。窗口最大32×32768，其百分比判断最大约1.05亿，低于 int32 上限；RPM窗口最大16项，和约52万。长期显示累计计数用饱和加法（:920）。极端计数输入、IRQ边界和停机锁定已有测试。
- **单位分离。** 轮速为 RPM；位移 mm；角度内部 rad；PID dt 秒；计时 ms。OLED A 为带符号的局部角度（左正、右负），Recovery 累计角度为绝对值之和；进入一次新局部修正时 A 归零不等于会话清零。
- **正负速度对称。** SpeedOutput 取目标绝对值，将反馈投影到本方向，最后恢复 PWM 符号；正反缓存分开。原硬件符号宏保持。真正换向经过零命令，并有撤驱动/惯性等待；方向故障的宽容期从新方向 PWM 真正施加才开始消耗。
- **PWM有界。** PID夹限、PWM斜率和最终夹限都保留；安全停机、明确零目标、换向等待及超速滑行可立即降到0。非零小目标不会因“低于10 RPM”被停轮，也没有把5 RPM抬成10 RPM。

## 本次修改后的再修正

1. 延后换向故障宽容的计时起点：先等新方向 PWM 实际出现，避免把正常撤驱动期间耗完260 ms宽容。新增正常换向延迟测试。
2. 恢复尝试耗尽后不能重启驱动：SetTargets 和 DriveTargets 都有停止态保护。
3. 出弯局部搜索保留原 exit_dir，不能把15°纠偏的反方向写成历史转向。
4. EXIT 的40/60 RPM档位同时要求时间和线稳定性，避免只按时间加速。角点 EXIT 要中心区域；普通弧弯 EXIT 保留稳定侧线，避免紧弧弯必须居中而被错停。
5. 删除旧恢复400 ms再压回42 RPM的使用路径，避免 EXIT→TRACK 后速度下降再爬升；参数名留作旧工程兼容。
6. 当前探头误差和历史偏差分开：旋转阶段的 OLED/调试显示真实本帧误差，方向选择仍保留历史信息。
7. 正常减速仅等量转移已验证负载补偿，再卸瞬态积分；不通过反复相加制造输出跳变。
8. 对称分离双黑区没有可靠历史时保持中性低速，240 ms 后停车，修掉按探头扫描顺序选左的隐藏偏置。
9. APPROACH入态首帧直接请求同步段28RPM，避免先短暂请求50RPM、下一帧再降到28RPM；左右方向测试同时检查此入口目标。

## 工程与验证边界

18个 Keil 引用的 C 单元通过 GCC 语法检查，63个源码/头文件引用存在；六个配置分支与五个分步提交分别通过 host 编译。原 `.uvprojx/.uvoptx`、启动/链接文件、Motor/PWM/PID/GraySensor 和 `build.ps1` 未改变。

64位host检查SPL的32位寄存器指针转换时，只对供应商代码关闭相应宽度告警；只对包含原字库的OLED单元关闭二维初始化 missing-braces 告警。应用控制代码保持 `-Wall -Wextra -Werror`。没有据此宣称 ARM 汇编、链接、Flash/RAM占用或20 ms实机耗时已经验证。

压力模型仍有一个右转矩形失败：第二角 ALIGN 后丢线，15°局部修正耗尽后安全停车。保留失败；没有扩大搜索预算、取消安全检查或放宽几何误差门槛来让结果显示通过。
