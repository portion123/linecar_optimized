## 阶段 1：修改方案（直接实施）

1. `hardware/Track.c/.h`：保留公共入口、分块读线与位置 PD，增加显式连续前进 / 内轮停转 / 原地反转模式；只在停车/换向清积分，避免状态切换清零目标；低速采用短窗口测速，反向故障以窗口计数与换向宽容判定。
2. `CarConfig.h`：集中低速、各阶段 RPM 斜率、角点计分、找线/对准/出弯、Recovery Session 与调试参数，保留硬件校准和 PI 增益；默认左参数停用。
3. `Track.c`：CONFIRM（整数置信计分）→ APPROACH（距离上下限、偏航检查）→ TURN_FAST / TURN_SLOW（50° / 70° 分段）→ ALIGN（低速前进差速）→ EXIT（斜坡恢复）。每段均有时间/距离/角度退出保护；方向未知只作对称小角试探。
4. `Track.c`：普通丢线保留短预测，再小角 / 扩角 / 有限反向；会话级时间、累计角度、次数、行程只在稳定 TRACK 后清除，假恢复不能刷新预算。
5. `Track.c/.h`、`OLED.c/.h`：保留 OLED，改为缓冲加空闲分片发送；增加默认关闭的调试快照，避免阻塞 USART printf。Keil 工程不新增硬件编译单元。
6. `tests/`：沿用真实 C harness；扩展用户要求的14类状态/方向/连续性/故障场景；原测试中“2帧即恢复、默认大角搜索、80ms停车即RUN”等被设计明确替代的断言会更新并记录，原算法基线保存在 Git。

保守假设：bit0 从车顶看在左，误差负→左，正→右；角度 `(right_mm-left_mm)/133` 为左正；摩擦和出弯线宽未经实车测量，正反补偿初值相同但各轮各方向可独立调。方向完全未知不猜固定左/右，采用等速前进小幅预测；仍不能确定时停车，或由对称侧向信号触发小角试探。
