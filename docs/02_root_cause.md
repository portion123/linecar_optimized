# 02 根因：由逐帧 trace 支撑的因果链（FIX4_SAFE）

工具：`python3 sim/trace.py <variant> '<族|种子|侧>' --t0 --t1`，列出每 20 ms 的
raw mask → 状态 → 请求目标 RPM → slew 后命令 → PWM → 模型轮速/编码器计数。
下面所有帧号/时间来自本仓库实际运行，非推测。没有任何一条根因需要“右轮经验补偿”。

## R1 弱横带被当作线跟随 → 车头偏转 → 尾部被判为普通弯 → 角点证据被清 → 额外 SEARCH（动态镜像退化）

样本：SQ2 种子 30000，左转(+) 与右转(−) 的第一个角，原 SquarePlant 模型。

| 帧(ms) | 左转 + | 右转 − |
|---|---|---|
| 进入横带 | 5120 mask 00011111（5 路，含中心+左边缘） | 5200 mask 11111000（5 路，含中心+右边缘） |
| FIX4 判定 | count=5 <6 → 不是 strong，只 wide_active；照常 FollowLine，误差 −3 → 请求 L30/R65 | 误差 +3 → 请求 L65/R30 |
| 内轮 | 左轮 PWM 5160 起=0，轮速 60→20 RPM（左电机 τ=0.12 s，响应快） | 右轮 PWM 5240 起=0，轮速 59→30（右电机 τ=0.20 s，响应慢） |
| 车头偏转（横带期间） | +3.4°（1.6→5.0°） | −1.9° |
| 横带尾 | 偏转使探头阵列倾斜，右侧先离开横带：00001111→00000111→00000011→00000001 | 一次性变全白 |
| FIX4 尾规则 | `!wide_strong && count≤宽+1 && |E|≥4` 连续 60 ms → **ClearWide**（“弱宽区缩成侧边窄线=连续弯”） | 不触发 |
| 结果 | 5380 全白、5440 进入 SEARCH（向左 36 RPM 扫），在 31.5° 找到线 | 5380 进入 APPROACH → 正常 90° 转 |

**首个分歧周期**：横带期间内轮 PWM 被 PD 拉到 0 的那几帧（5160 vs 5240），因左右电机时间常数不同造成的偏航差，
使左转横带尾部逐帧向边缘收缩。耦合链：*弱横带被当线 PD 跟随（无方向锁定）→ 偏航 → 尾部形态变化 → 尾部规则误清角点 → 普通失线 SEARCH*。
SQ2 统计：左转 54 次 SEARCH、右转 4 次；BEND 左 31/右 2。根因在逻辑耦合，不在右轮标定。

证据（BEND 全 60 run）：≥5 路连续、含中心且只触一侧边缘的形态共 1562 帧，**全部**位于直角顶点 60 mm 内，圆弧（R150–300）从未出现。

## R2 真角尾部（胶带越过角点的残段）超过 200 ms 记忆 → 角点证据过期 → SEARCH 从错误位置找线

样本：TAIL 种子 33022+（残段 19.1/24.8/21.9/22.9 mm）。5320 ms 6 路强横带 00111111 → WIDE，方向 −1；
5380–5520 残段只在第 5 路（00100000）可见，车按 WIDE 直行 50 RPM；残段帧无边缘位，不刷新 `wide_last_seen`；
5540 首个全白帧时距最后横带帧已 220 ms > `CORNER_MEMORY_MS`=200 → **ClearWide**，不进入 APPROACH；
80 ms 后 SEARCH（轴心距角点仍约 130 mm），在 36° 找到出线，以大角度斜切上线，TRACK 误差 40 mm（判据 35 mm）。
居中的残段则被 `CORNER_CLEAR_CENTER_MS`=100 ms/8 mm 清除，结果相同。TAIL 失败 31/60 全部属于这一类。

## R3 推进阶段无偏航保持 → 超出 15° 推进预算

样本：GEO loaded_square_+1。推进中两轮都只请求 50 RPM、无偏航修正；负载模型左轮积分追得慢，
左 ~38 / 右 ~52 RPM 持续，165 mm 内偏航 >15°。FIX4 继续推进再靠 55–105° 扫描吃掉偏差；FIX4_SAFE 按硬约束停车（原因 9）。
影响 28 run（其中 13 个 FIX4 原本通过）。

## R4 转角捕线：见线后仍强转、居中两帧后整车 PWM=0 + 清 PI + 80 ms 停顿 → 过冲、停车、重新起步

样本：SQ2 30000−（右转）。7920 ms 出线进入最外第 7 路（−75°），FIX4 因“含边缘不减速”继续 42 RPM 原地转；
8000 第 6 路才降到 30 RPM；8140 中心两帧 → EXIT：`SetPWM(0,0)`、`ResetPID()`、80 ms 等待，车靠惯性继续转到 −98.4°（过冲 ~6°）；
8220 进入 RUN，命令从 0 按 5.4 RPM/帧重新爬升（重新起步/kick）。
**撤强延迟**（可信线 → 请求旋转分量 ≤12 RPM）全族中位数 200 ms、p95 300–320 ms。
FIX4 自己已有连续接回路径 `ResumeLine`（不清速度积分、不刹停、原 PD+限速 42 RPM），但只用于普通 SEARCH，直角没有用。

## R5 白缝在“慢速”时超过 80 ms → 大范围 SEARCH（动态模型）

样本：MIX 37009+。动态模型下 FIX4 超速松驱动规则（滤波转速 > 命令+12 → PWM=0）与 TB6612 滑行形成极限环，
PWM 在 0↔15% 跳、轮速 20–85 RPM；经过圆弧后 4–10 mm 白缝时车几乎停住，全白 >80 ms →
SEARCH 两侧 60° 都找不到（线就在正前方）→ 原因 13 停车。

## R6 EXIT 首帧单帧白 → 立即反向大范围 SEARCH

FIX4 EXIT 等待 80 ms 后只看**一帧**：`if(!count) BeginScan(-corner_dir,0)`，单帧漏读/噪声即进入 60° 搜索。

## 与修复的对应

| 根因 | 修复开关（见 docs/09） |
|---|---|
| R3 | TRACK_APPROACH_HOLD_ENABLE |
| R1、R2 | TRACK_CORNER_BAND_ENABLE（≥5 路单边横带两票锁定方向、按距离保留真角尾部） |
| R4、R6 | TRACK_CORNER_CAPTURE_ENABLE（可信线两帧即撤强转、走 FIX4 原 ResumeLine 连续接回） |
| R4 后段 | TRACK_STABLE_RESUME_ENABLE（低速接线后按稳定条件而非固定 400 ms 恢复高速） |
| R5 | TRACK_WHITE_DISTANCE_ENABLE（白缝按行进距离给缓冲） |
