调参过程中的两处修订（均为逐帧 trace 支持、全矩阵复核，不是按单个种子凑数）：
1. 白缝判据 |E|≤1.5 → ≤3.0：线在 ±3 内消失而未经过边缘探头，物理上只能是断线/白缝，弯道离线一定先经过 ±5 以上（MIX 37005−）。
2. 回扫允许按相对原航向的绝对转角接线：首侧已扫过的 55–105° 出线在回程可接住；旧线在 180° 附近，不会误认（MIX 37025+）。
3. 横带判断填补单探头漏读（仅用于横带证据，循线误差仍用原读数）：8% 漏读把 5 路横带拆成“中心+左块”，FIX4 选左块急转导致重载左轮
   PWM 归零，推进超 15°（FRD L2 seed13）。
